**Wheels / hubs**
- **Hubs list** (new): DT 180/240/350, Carbon-Ti X-Hub, Extralite Hyper, Light Bicycle Pace (295g pair HG, ceramic +US$40), Tune, Bitex, Chris King, Hubsmith R027 (214g rear), SMC RHET (~80-130g lighter than Hubsmith on SMC wheels). Ceramic-versions table. Buy **centre-lock, HG freehub**.
- **Wheelsets**: ranked 406 disc list. **New lightest: SUNCORD carbon-spoke 406, 930g, S$1,780 (KaiCycle SG)** — confirm 12mm thru-axle/142 adapter and HG freehub. SMC Plume DW2 + RHET 945g stays the pick. Custom floor ~920g.
- 16" reference (❌ not compatible): Extralite CyberCity 349B 539g (€2,252; US$2,917 Brombacher pre-order), Wheel Angel × Extralite 675g (confirmed 349 rim brake).
- **Aluminium 406 options**: Alienation Mischief 290g / TCS Malice 325g (tubeless, US$75-104) custom builds ~1,040-1,140g; Hubsmith Bumbee A406 for G Line S$1,224 (16B Cycle, weight unpublished).

**Brakes** (full rewrite of the levers/rotors sections, plus a caliper list; each item labelled mechanical / hybrid / hydraulic)
