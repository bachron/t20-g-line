# Tools for the T20 / G Line build

**Created:** 27 Sep 2026
**⚠️ Separate list. Tool costs are NOT part of any build cost** in `T20_Build_Comparison.md` or `T20_Build_Plan.md`. Tools are a one-off workshop purchase that outlasts the bike.

Brands, best known first. Details from general knowledge, not a fresh search. **Confirm tool fit against the exact part you buy** (notch counts and sizes vary by brand).

## Tool list

**Key:** ✅ needed on every build · ⚙️ depends on a parts choice · 🏪 often cheaper to let a shop do it once

### Essential

| Tool | Why for this build | Brand options |
|---|---|---|
| ✅ **Torque wrench, ~2-15 Nm** + bit set | Carbon bar, carbon fork steerer/stem clamp, seatpost clamp, spider and chainring bolts, Ti bolts. Over-torque cracks carbon | Silca, Feedback Sports, Park Tool (ATD / TW-5.2), Wera Click-Torque, Topeak |
| ✅ **Hex (Allen) key set** 2-10mm | Almost every bolt on the bike | Wera, PB Swiss, Bondhus, Park Tool |
| ✅ **Torx key set** T10-T30 | Rotor bolts, some chainring bolts and stem bolts | Wera, PB Swiss, Park Tool |
| ✅ **Bottom bracket tool** | Fitting the new BBInfinite/Praxis M30 BSA bottom bracket. ⚠️ Match the cup notch pattern and diameter to the BB you buy | Park Tool BBT series, Unior, Shimano TL-FC range, Wheels Mfg |
| ✅ **Cassette lockring tool** + **chain whip** | Fitting and removing the cassette (Shimano HG and SRAM XD both use the common splined lockring tool) | Park Tool FR-5.2 + SR-2, Unior, Pedro's |
| ✅ **Chain tool** + **quick-link pliers** | Cutting the chain to length for 20" wheels, joining it | Park Tool CT-3.3 / MLP-1.2, Wolf Tooth Pack Pliers, KMC |
| ✅ **Cable and housing cutter** | Shift cables and any mechanical-brake cables (you're fitting new cables) | Park Tool CN-10, Jagwire Pro, Knipex |
| ✅ **Cable-end crimper** | Crimping cable end caps | Usually built into the cutter above |
| ✅ **Pedal spanner** (15mm) or long hex | Pedal install. Most modern pedals take an 8mm hex | Park Tool PW-5, Pedro's |
| ✅ **Tyre levers** + **floor pump with gauge** | Tyres and tubes (Conti Contact Urban) | Park Tool, Pedro's, Silca, Topeak, Lezyne |

### Depends on your parts choices

| Tool | When you need it | Brand options |
|---|---|---|
| ⚙️ **Centerlock rotor lockring tool** | Centerlock rotors. **Thru-axle hubs usually use the external-notch lockring**, which needs a BB-style tool; internal-spline lockrings take the cassette tool | Park Tool BBT-69.2 (external) / FR-5.2 (internal), Shimano TL-FC36 |
| ⚙️ **Hydraulic brake bleed kit** | Only for full-hydraulic brakes. **Shimano (mineral oil) and SRAM (DOT fluid) kits are not interchangeable.** Not needed for mechanical (Growtac, TRP Spyre) or self-contained semi-hydraulic (Juin Tech GT-F) calipers | Shimano official kit, SRAM Pro Bleed Kit, Park Tool BKM/BKD |
| ⚙️ **Flat-mount / 160mm adapters** | Brake route 2 or 3 (160mm rotors). A part, not a tool, but fitting needs the torque wrench | Shimano SM-MA, Wolf Tooth, TRP |
| ⚙️ **Di2 / AXS charger + app** | Electronic shifting. Charger comes with the kit; the setup app is free | Shimano E-TUBE, SRAM AXS |

### Worth having

| Tool | Why | Brand options |
|---|---|---|
| **Derailleur hanger alignment gauge** | Folding bikes knock the hanger in the fold and on trains. A bent hanger ruins shifting | Park Tool DAG-2.2, Abbey HAG, Unior |
| **Chain wear checker** | Replace the chain before it wears the cassette and carbon chainring | Park Tool CC-4, Pedro's, KMC |
| **Repair stand** | Makes the whole build much easier. Clamp the alloy/Ti seatpost, **never a carbon part** | Feedback Sports Pro Elite, Park Tool PCS series |
| **Cable housing awl / bench vise** | Clean housing ends and routing | Park Tool |

### 🏪 Shop jobs (or buy if you'll build more bikes)

The T20 frame arrives **unassembled**, so these jobs come up once:

| Job | Tool | Note |
|---|---|---|
| **Headset cup install** | Headset press + crown race setter | Park Tool HHP-3, Unior, Cyclus. One-off; a shop can press the cups |
| **BB shell thread chase / face** | BSA tap and facing set | Cyclus, Park Tool BTS-1. Worth having a shop check the 3D-printed Ti BB shell threads before fitting the BB |
| **Wheel truing** | Truing stand + spoke key | Park Tool TS-2.3, Feedback Sports. Mostly for a custom hub build |

### Consumables (not tools, but you'll need them)

- **Anti-seize or Ti prep** for every titanium thread (Ti frame, Ti seatpost, Ti bolts). Titanium seizes without it.
- **Carbon assembly paste** for carbon clamping areas (bar, fork steerer, seatpost clamp).
- **Bearing grease**, **medium threadlocker**, **isopropyl alcohol** (rotor and pad cleaning), rags.
- **Chain lube** suited to Singapore rain.
